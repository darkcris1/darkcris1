## About me

5+ years building web apps for real estate sales, HR and payroll, and live drone tracking. Django and Python on the server, Angular, React or Svelte in the browser, AWS and Terraform underneath, and Claude Code in my workflow.

I care most about system architecture, performance and code that stays easy to change. I like working closely with a team, mentoring junior developers, and keeping up with what's new, which lately means putting AI to work in my day-to-day development.

## What I do

- **Full stack web apps:** Django and Python APIs with Angular, React or Svelte front ends, backed by PostgreSQL and Redis.
- **Cloud infrastructure:** AWS environments defined in Terraform, so every setup is versioned, reviewed and repeatable. Docker and Nginx for deploys.
- **AI-assisted development:** I work with Claude Code to plan changes, refactor, write tests and review code, so I ship faster without lowering the bar.

## Featured projects

- **Multi-Tenant Headless CMS:** runs many websites from one dashboard, with browser-based Nunjucks templates, a block editor, versioned pages and a headless content API. _SvelteKit, PostgreSQL, Drizzle, Terraform, AWS ECS_
- **IP Geolocation Data Pipeline:** daily merge of MaxMind, IP2Location and DB-IP into one IP-to-location dataset, shipped as MMDB, Postgres and S3 outputs. _Python, FastAPI, DuckDB, Go, AWS Fargate_
- **[Pueblo De Oro (PDO)](https://pueblodeoro.com):** manages agents, properties and clients for buying property in the Philippines. _Angular, Django_
- **[Emergency Management System](https://optixvue.com):** real-time emergency drone tracking, reporting and analysis. _Angular, Django_
- **[HomeKey](https://www.homekey.com.ph):** connects real estate developers and lenders with balikbayan home buyers. _Angular/Ionic, Django_
- **HRMS:** employee data, payroll, attendance and performance reviews. _Angular, Django_

More on [my portfolio](https://crisfandino.vercel.app/#projects).
